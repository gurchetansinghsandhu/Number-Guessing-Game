# Number-Guessing-Game
A Number Guessing Game in python is a simple but effective interactive game where the program randomly selects a number within a specified range ,and the user has to GUESS it. 
The game typically continues until the player guesses the correct number. It’s a great beginner project to practice and This project allowed me to reinforce my understanding of python and its applications in web development.
Its incredible to see how few lines of code can create an interactive game loved by millions.
Features of number guessing game in python: random number generation, user input and loop until correct.
